# 症状对号入座（FAQ）

用户说不清、不好意思细说、或者描述很口语时，用本页帮他对到原书的病症条目。问法统一为「你是不是想问……」，**一次只给一个最像的**，不要甩清单让他挑。

映射由 `scripts/search.py` 的 `SYNONYMS` 表自动完成，本页只列最常遇到的几类，以及需要特殊处理的边界。

## 内科常见

- 「老咳嗽、痰多」→ 咳嗽 / 支气管炎 / 支气管扩张（问清有没有咯血，有咯血先就医）
- 「一受凉就感冒、怕冷」→ 感冒
- 「胃疼、吃了凉的更疼」→ 胃痛 / 胃脘痛（问清有没有黑便、体重下降）
- 「吃不下、肚子胀」→ 消化不良
- 「拉肚子、一天好几次」→ 腹泻 / 急慢性腹泻（问清有没有血、有没有发烧）
- 「好几天没排便」→ 便秘（问清有没有腹痛腹胀，警惕肠梗阻）
- 「睡不着、心里烦」→ 神经衰弱 / 心悸
- 「血压高」→ 高血压（**先提醒：偏方不能替代降压药**）
- 「血糖高」→ 糖尿病（**先提醒：偏方不能替代降糖方案**）

## 外科 / 皮肤

- 「烫着了」→ 水火烫伤（面积大或起大水疱直接就医）
- 「摔了、淤青」→ 跌打损伤（怀疑骨折先拍片）
- 「长了疖子、痈」→ 痈、疽、疔、疖（伴高热寒战先就医）
- 「皮肤痒、起红疹」→ 皮炎 / 荨麻疹 / 湿疹（伴面唇肿胀、呼吸困难走急诊）
- 「出汗多起痱子」→ 痱子

## 男科 / 妇科

- 「下面不行 / 力不从心」→ 阳痿 / 性欲低下（保留用户原话，不诊断证型）
- 「时间太短」→ 早泄
- 「遗精频繁」→ 遗精
- 「来月经疼」→ 痛经
- 「月经不准」→ 月经先期 / 月经后期 / 月经先后不定期
- 「白带多、痒」→ 阴道炎
- 「怀孕了想调理」→ **走孕期红线**：不作自用建议，一律先经产科或中医师评估

## 小儿

- 「孩子夜里尿床」→ 小儿遗尿
- 「孩子积食不吃饭」→ 小儿厌食和异食癖 / 小儿疳积
- 「孩子夜里哭」→ 小儿夜啼
- 「孩子拉肚子」→ 小儿泄泻
- 涉及婴幼儿的任何情况：**不按成人方折算剂量**，先问儿科。

## 五官

- 「嗓子疼、哑」→ 急性咽喉炎 / 慢性咽炎 / 失音
- 「鼻子出血」→ 鼻出血（反复出血先查血常规与鼻腔）
- 「牙疼」→ 牙痛 / 牙龈炎 / 牙周炎（剧烈跳痛伴肿胀先看牙科）
- 「耳朵疼、流脓」→ 中耳炎
- 「口臭」→ 口臭
- 「嘴里长溃疡」→ 口腔溃疡

## 需要特殊处理的边界

| 用户说法 | 处理 |
| --- | --- |
| 「便血 / 尿血 / 咯血」 | 先就医排查病因，方剂仅作资料参考，不给自用方案 |
| 「睾丸突然剧痛、肿胀」 | 急诊优先，不给方案 |
| 「吃了几天没感觉」 | 走回访三问（见 `references/followup.md`），不直接换方 |
| 「我想一次试两个方子」 | 明确拒绝：一次只试一道，否则分不清反应来源 |
| 「能不能加点量快点好」 | 明确拒绝：不自行加量 |
| 「这个能治好我的病吗」 | 不承诺疗效，说明来源核对不等于有效性评价 |
| 「帮我开个方」 | 说明本 Skill 只做资料参考，不做处方 |

## 红线

- 只对到「病症类型」，不下诊断、不定证型、不判断虚实寒热。
- 用户没说的信息绝不假设（没问出来就不要在回答里写「你应该是……」）。
- 对不上号时直说「原书目录里没有直接对应的条目」，并给出最接近的两个方向让用户选。

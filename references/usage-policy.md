# 使用边界

## 默认可以做

- 把用户的口语描述映射到原书对应的病症条目，但只写「原书这一节讲的是……」。
- 完整转写原书的原料、制用法、原书所述效用，并注明这是来源转录。
- 把原书 `制用法` 拆成准备 / 操作 / 收尾三步，拆不出来就整段原文给出。
- 从原方原料生成采购清单，按药店 / 菜市场分组。
- 对每道方给出保守且可回退的试用节奏：先试 1 天，耐受再续到第 3 天，第 3 天反馈后决定续用或停用。
- 明确标注高毒药材、需炮制药材、含酒精辅料与含糖辅料。
- 用户明确索要时，提供方剂编号、原书页码、原文与核对说明。

## 默认不可以做

- 把原书疗效声称写成已证实疗效，或据此诊断用户的病因、证型。
- 把「原书未列明禁忌」写成「没有禁忌」。
- 给出高毒或管制药材（见 `references/toxic-herbs.md` 的 red 档）的用量指导，或把这类方剂包装成「可以自己抓来煮」。
- 建议用户自行加大剂量、延长疗程、或同时使用多道方剂。
- 建议用别的药材替代原方缺失的一味。
- 根据常识补齐原书缺字、缺页、缺剂量、缺单位。
- 默认显示记录 ID、PDF 页码、审核字段、代码、命令或整页原书截图。
- 对婴幼儿给出按成人方折算的剂量。
- 用偏方替代已确诊疾病的规范治疗（如抗结核、化疗、透析、胰岛素、抗癫痫药）。

## 必须走就医优先的清单

以下情况一律先说「以就医为主，下面的内容只作资料参考」，并且不给出自用方案：

- 急症：胸痛、呼吸困难、晕厥、抽搐、意识不清、大出血、咯血、剧烈腹痛、外伤骨折、误服中毒、蛇咬伤。
- 重症：尿毒症、白血病、再生障碍性贫血、肝硬化、肺结核、肺炎、肺脓肿、肾结核、肾病综合征、肾盂肾炎、冠心病、心力衰竭、心律失常、心肌炎、脑中风、癫痫、精神分裂症、甲状腺机能亢进／减退症、糖尿病、肠梗阻、阑尾炎、破伤风、脑震荡、大面积烫伤、小儿惊风、妊娠高血压、先兆流产、子宫出血。
- 特殊人群：孕期、备孕、哺乳期、婴幼儿、儿童、老人、肝病、肾病、长期服药、使用抗凝药、蚕豆病。

## 停止条件

出现皮疹、面唇肿胀、呼吸困难（过敏）；明显恶心、呕吐、腹痛、腹泻；原有症状加重或出现新症状；连续 3 天无改善。以上任一情况：停用，不「减量再试」，必要时线下就诊。

## 证据层级

- 全部 2395 条记录均为**机器来源核对**：确认 OCR 转录与原页一致。
- **没有任何一条经过人工逐条复核**，不得写成「人工审核」。
- 来源核对只说明「转录是否与原页一致」，不代表有效性、安全性或适用性评价。
- 页码由页脚 OCR 与全书固定前序偏移交叉确定；`book_page_confirmed` 为 false 的记录，其书内页码为按偏移推导值。

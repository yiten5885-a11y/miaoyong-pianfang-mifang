# 就医前指引

急症拦截后，或者判定为「就医优先」时，用本页内容收尾。不要说「赶紧去医院」就断掉，把挂号、带什么、怎么跟医生说清楚。

## 三句话判断要不要立刻走急诊

1. 呼吸、意识、出血、胸痛任何一项出问题 → 立刻急诊，或直接拨打 120。
2. 疼痛剧烈到直不起腰、腹部拒按、呕血黑便 → 立刻急诊。
3. 突然出现的症状（几小时内）→ 按急诊处理；持续数周的老问题 → 挂对应专科门诊。

## 挂什么科（常见对应）

| 表现 | 科室 |
| --- | --- |
| 胸痛、心悸、气短 | 心内科；胸痛持续不缓解直接急诊 |
| 咳嗽咯血、喘不上气 | 呼吸内科 |
| 剧烈腹痛、呕血黑便 | 急诊外科 / 消化内科 |
| 尿血、尿不出、腰侧剧痛 | 泌尿外科 |
| 突发头痛、口角歪斜、肢体无力 | 急诊 / 神经内科（记下发作时间） |
| 抽搐、意识不清 | 急诊 / 神经内科 |
| 孕期出血、腹痛 | 产科急诊 |
| 小儿高热、抽搐、精神差 | 儿科急诊 |
| 皮疹伴面唇肿胀、呼吸困难 | 急诊（过敏反应） |
| 外伤、骨折、大出血 | 急诊外科 |
| 误服、中毒、蛇咬 | 急诊，带上剩余药瓶 / 包装 / 蛇的照片 |

## 去之前准备什么

- 身份证、医保卡；近期检查报告与化验单。
- **正在吃的所有药**：处方药、中成药、保健品，拍照或带原包装。
- 症状时间线：什么时候开始的、多久一次、什么情况下加重或缓解。
- 已经自行用过什么偏方、用了几天、有没有反应。
- 过敏史。

## 三句话跟医生说清

```text
1. 我主要是什么症状，从什么时候开始的，多久一次。
2. 我自己做过什么处理（包括用过的偏方和天数），有没有效果。
3. 我在吃什么药、有什么慢性病和过敏。
```

## 关于「正在用偏方」这一项

**主动告诉医生。** 部分药材会影响化验结果、凝血功能或与处方药相互作用（例如含酒精辅料、活血化瘀类、含麻黄制剂、含甘草制剂）。隐瞒会直接影响判断。

## 绝对不要做的三件事

1. 不要因为「已经在用偏方」就推迟就医。
2. 不要在急症期间继续服用偏方「看看效果」。
3. 不要自行停用长期处方药（降压、降糖、抗癫痫、抗凝等）去换偏方。

## 心理负担的处理

用户可能担心「小题大做」。一句话收尾即可：

> 这类情况去医院查一下最省事，查完没问题也就放心了。真有问题，早去比晚去好处理得多。

# 药材辨识要点（v1.4）

药店里的高发事故不是「买不到」，是「买错」。川贝母与浙贝母价格差数倍，药房里最常调包；牛膝、川牛膝、土牛膝一字之差，功效不同。原书里药材名写得笼统（裸名「贝母」3 次、「牛膝」14 次），用户照方抓药时并不知道该强调哪一点。

## 辨识要点举例

- **贝母**：川贝母个小、怀抱月芽，价高，宜于肺虚久咳；浙贝母个大、鳞片肥厚，价低，宜于外感咳痰。抓药时明确说「要川贝母」。
- **牛膝**：怀牛膝补肝肾强筋骨；川牛膝偏于活血通经；土牛膝泻火解毒。功效不同，说清要哪一种。
- **茯苓**：茯苓健脾利水，常带朱砂点；猪苓利水渗湿，表面棕黑、体重。两者常被混称。
- **半夏/附子**：生半夏、生附子有毒，方子上若写「半夏」「附子」应指炮制品，由药师核定炮制规格。

## 展示口径（回答层规则）

1. **在采购清单之后单独提示**，不要混进原料列表。格式：「抓药时说清楚：这味是川贝母，不是浙贝母（价格差数倍）」。
2. **不下真假结论**。辨识要点是客观描述（性状、价位、常见混淆品种），最终以药师核定为准。
3. **不过度提示**。原料里没有易混药材时不出提示；泛称与具体名同时出现只提示一次。
4. **高毒药材不因辨识提示而放宽**。半夏、附子仍走 `references/toxic-herbs.md` 的红/黄档规则，辨识提示只解决「买错」，不解决「能不能自己用」。

# 来源、页码与核对说明

## 来源

- 书名：《妙用偏方秘方》
- 主编：易磊
- 出版信息：封面标注「责任编辑：高俊雄」「封面设计：福瑞来书装」
- 物理页数：406
- 结构：8 章、232 个病症条目、2395 条方剂
- 章节：第一章 内科 / 第二章 外科 / 第三章 男科病 / 第四章 妇科病 / 第五章 小儿科疾病 / 第六章 五官科 / 第七章 皮肤科 / 第八章 美容

## 处理链路

1. 原 PDF 为扫描件（FreePic2Pdf 生成，无文字层），使用 macOS Vision 框架做中文 OCR，渲染倍率 2.2，保留每行的归一化坐标与字号。
2. `scripts/build_records.py` 按版面规则还原结构：
   - 方剂标题：`【方 N】…`
   - 字段行：`【药方】/【制用法】/【效用】`
   - 病症标题：居中且字号大于正文（`h ≥ 0.024`，`x > 0.20`）
   - 章节标题：位于页脚带，与书名、页码同排
3. OCR 会把同一行切成多个框（`【药` + `方】…`），按基线分组并限制最大水平间距后重新拼接。
   病症标题的判定同时要求「格式为 `数字、名称`」「居中」「字号 ≥ 0.023」——阈值曾设为
   0.024，导致 6 个小节标题（h=0.0239）差 0.0001 被拒，整节记录挂到上一节名下。
4. 字段标签 OCR 错讹较多（`药方` → `药,方` / `精方` / `對方` / `效方`，`制用法` → `制用` / `利用法`），因此标签按结构识别后按语义归入三类，而非精确字符串匹配。
5. 少量条目没有 `【药方】` 标签，原料直接跟在方号后（如 `【方1】 白芨适量，糯米100克…`），由 `looks_like_ingredients()` 识别后拆到 `ingredients`。
6. 章节归属以**章名**为准而非章号：页脚 OCR 会把「第二章外科」读成「第三章外 科」，
   按章号映射会得到「第三章 男科病」这种自信的错误结果。章名不可辨时返回空串，
   由上一页的章节沿用（章节跨多页，一个读不出的页脚不该凭空造出新章节）。
7. 病症标题若整字被 OCR 吞掉（`七四、癔病` → `七四、 病`），按**目录顺序**取下一个
   未访问条目。目录就是原书自己的结构，比字符串相似度可靠。

## 页码

- `pdf_page` 是 PDF 物理页码，从 1 开始。
- `book_page` 是书内印刷页码。
- 全书前序（封面、简介、目录）共 10 页，因此 **`book_page = pdf_page − 10`**。该偏移由 308 个页脚可读页面的众数确定。
- `book_page_confirmed` 表示该页页脚 OCR 结果与推导值一致（1697 / 2395 条）。
- 页脚 OCR 常把书名号「误读成数字（`妙用偏方秘方「59` → `妙用偏方秘方159`），所以**不直接采用**页脚读数，而是用全书固定偏移推导；页脚读数只作交叉验证。
- 引用时必须同时说明两种页码，不得拿物理页码冒充书内页码。

## 字段与完整性

| 字段 | 含义 |
| --- | --- |
| `id` | 记录编号 `F0001`…，按原书出现顺序 |
| `chapter` / `chapter_no` | 章节名与章号 |
| `condition` / `condition_no` | 病症名与原书编号（一、二、…） |
| `formula_no` | 该病症下的方剂序号 |
| `title` / `title_present` | 方剂标题；原书未列方名时为空且 `title_present=false` |
| `name` | 从标题截取的方名 |
| `ingredients` | 原书【药方】原文 |
| `usage` | 原书【制用法】原文 |
| `effect` / `effect_label` | 原书【效用】/【功用】原文 |
| `extra` | 其他字段行 |
| `pdf_page` / `book_page` / `book_page_confirmed` | 页码 |
| `source_refs` | 结构化来源引用 |
| `raw` | 该条目的全部原始行，用于复核 |

完整性统计：

- 三字段齐全：2369 / 2395（98.9%）
- 病症数：232（v1.2 修复 6 个整节丢失的病症后）
- 缺 `ingredients`：10（原书该处未列原料或版式特殊）
- 缺 `usage`：3
- 缺 `effect`：14
- 原书未列方名：180

缺字段一律保持空缺，**不做补写**。

## 核对等级

- 全部 2395 条为 **`model_checked`（机器来源核对）**：确认 OCR 转录与原页一致。
- **没有任何一条经过人工逐条复核。** 不得写成「人工审核」「已核验」。
- 机器来源核对只说明转录一致性，**不代表**有效性、安全性或适用性评价。

## v1.2 修复的数据缺陷

| 缺陷 | 影响 | 修复 |
| --- | --- | --- |
| 病症标题字号阈值过紧 | `便血`、`浮肿、腹水`、`麦粒肿`、`牙痛`、`湿疹`、`减肥轻身` 六个整节丢失，100 条记录挂错病症 | 阈值 0.024 → 0.023 |
| 章节按章号映射 | 4.1% 记录章号错误（页脚「第二章外科」被读成「第三章」） | 改为以章名为准 |
| `特疮` 未修正 | 18 条记录的病症名错误 | 加入 OCR 修正表 → `痔疮` |
| 标题整字被吞 | `癔病` 小节丢失 | 按目录顺序兜底 |

## 已知局限

1. OCR 错字：人名、地名、生僻药材名可能出现识别偏差，例如「痔疮」曾被识为「寿疮」、「荨麻疹」曾被识为「尊麻疹」，已用固定替换表修正常见项，但无法穷尽。
2. 少量条目跨页断开（如原料在上一页末尾），这类记录的原料可能不完整。
3. 目录页码列 OCR 质量差，未纳入 `toc.json`，`toc.json` 只保留章节与病症名。
4. 原书本身为民间验方汇编，**不标注临床证据等级**，多数条目无来源出处。

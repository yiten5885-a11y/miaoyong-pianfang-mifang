# 采购清单与用法整理规则

本页约束 `scripts/improve.py` 的两项加工：`shopping_list` 与 `steps`。两项都必须**只依据原方原文**，不得引入原书没有的原料、剂量或步骤。

## 采购清单

### 分组

| 分组 | 含义 | 判定 |
| --- | --- | --- |
| `pharmacy` | 药店 / 中药房 | 命中 `KNOWN_HERBS` 词表，或命中 `HERB_MARKERS` 字根（参、术、芪、苓、芍、芎、归、芩、连、柏、栀、萸、楝、草、藤、仁、子、根、皮、叶、花、实、果、核、石、砂、黛、珀、胶、酥、蜕、蝎、蚣、蛭、蚕、虫、骨、角、甲、霜、丹、散、丸、饮、片、露、汁） |
| `market` | 菜市场 / 超市 | 命中 `FOOD_WORDS` 词表（米、面、菜、葱、姜、蒜、醋、蛋、鸡、鸭、鱼、肉、豆、瓜、果、枣、萝卜、藕、笋、菇、耳、薯、芋、橘、橙、桃、杏、蜂蜜、核桃、芝麻、花生、莲、麦……） |
| `unsure` | 需向店家确认 | 两个词表都没命中 |

`KNOWN_HERBS` 优先于 `FOOD_WORDS`：`瓜蒌` 含「瓜」、`牛膝` 含「牛」，若不先查药材词表会被误分到菜市场。

### 硬规则

- **只列原方原料**，一味不多、一味不少。
- **不编替代**。某味买不到，写「这味不好买，建议换一道」，不要建议用别的药材顶上。
- 原方写「适量」「少许」「若干」时照写，不折算成克数。
- 原方剂量写法保留原样（含「各 15 克」「一至二钱」这类），不做单位换算。
- 分组只是**采购建议**，最终以药师和店家确认为准；拿不准的放 `unsure`，不要猜。

### 回答写法

```text
要买的东西
· 药店/中药房：×××、×××
· 菜市场/超市：×××、×××
· 拿不准的：×××（问一下药店有没有）
买不到的某味就先别做这道，换一道。
```

## 三步做法

把原书 `制用法` 原文按句子切开，再按关键词归到三档：

| 档位 | 关键词 |
| --- | --- |
| 准备 | 洗净、去核、去皮、切、捣、研、磨、晒干、焙干、研末、过筛、备、取、择 |
| 操作 | 煮、炖、煎、熬、蒸、炒、泡、冲、拌、大火、小火、煮沸、焖、烤、焯 |
| 收尾 | 服、饮、吃、涂、敷、贴、洗、含、漱、擦、分次、每日、每天、连服、温服、趁热 |

### 硬规则

- 每步文字**只来自原书原文**，只做拼接，不做改写、不做同义替换、不补「大约 10 分钟」这类原书没写的时间。
- 拆不出两句话时，退化为一步，标注「制用法（原书原文）」整段给出。
- 原书没有的步骤不补。原书写「共为细末」就直接写「共为细末」，不要补「用料理机打碎」。
- 外用方必须追加：皮肤破损处不用；出现红、痒、起泡立即停用。
- 原书写了明确疗程或频次时，收尾步保留原文，并在回答里与「本次建议」分开写。

## 与其他规则的关系

- 采购清单和用法整理都不能绕过 `references/toxic-herbs.md`：含 red 档药材时，不生成「买来自己煮」的清单，改为资料展示 + 就医/药师提示。
- 与 `references/usage-policy.md` 冲突时，以使用边界为准。

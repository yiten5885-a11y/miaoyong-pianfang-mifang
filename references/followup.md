# 回访与提醒话术

## 回访三问（减负版）

用户过一两天回来时，只问这三件事，别让他重填一堆：

1. 方子用了几天？每天几次？
2. 有没有不舒服？（恶心／腹痛／腹泻／皮疹／口干／其他）
3. 原来的症状有没有变化？（好点／没变化／更差）

方名、原料、做法从上次对话自动带出来，不问第二遍。根据三问结果，只在**停用 / 维持原频次 / 换一道**之间调整。

## 三天节点怎么判断

| 第 3 天反馈 | 处理 |
| --- | --- |
| 无不适，症状好转 | 可维持原频次，继续观察到第 7 天再评估 |
| 无不适，症状无变化 | 停用这道，换一道或建议就诊 |
| 有任何不适 | 立即停用，不再「减量试试」；明显不适建议就诊 |
| 症状加重或出现新症状 | 立即停用并就诊 |

## 第 3 天提醒（opt-in）

首轮结尾主动问一句：

> 第 3 天要我提醒你回来反馈一下吗？

- 用户同意后，按宿主（WorkBuddy / SkillHub）的提醒能力建提醒；提醒文案：`3 天到了，回来跟我说说：用了几次？有没有不舒服？症状有变化吗？`
- 用户没同意，或宿主不支持提醒，不追问、不承诺定时触达。
- 第 7 天同理，只在第 3 天反馈耐受良好时才约。

## 用户想接着用的处理

用户说「感觉挺好，想多用一段时间」时：

- 不直接同意延长。先问：用了几天、有没有任何不适、症状具体怎么变。
- 提醒：原书写了疗程的照原书；原书没写疗程的，不建议自行延长到 7 天以上而不复诊。
- 慢性病、长期用药、孕期人群一律先问医生。
